# Викторина «Смех да и только» (C#, Windows Forms)

Лёгкая юмористическая викторина из 15 вопросов с вариантами ответов.

## Окна приложения

1. **Стартовое окно** (`StartForm`) — правила и ввод имени.
2. **Окно вопроса** (`QuestionForm`) — для каждого из 15 вопросов открывается новое окно
   с 4 вариантами ответа (порядок вариантов перемешивается).
   - Если ответ **неправильный**, появляется `MessageBox` «Неправильный ответ!»,
     выбор сбрасывается, и нужно ответить на тот же вопрос заново.
   - Если ответ **правильный**, открывается окно следующего вопроса с шуткой к предыдущему.
   - При закрытии окна крестиком программа спросит, точно ли игрок сдаётся, и вернёт на старт.
3. **Окно результатов** (`ResultForm`) — количество ошибок и шуточное звание;
   можно сыграть ещё раз или выйти.

## Запуск

Нужны Windows и .NET 8 SDK (или Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений .NET»).

- Visual Studio: открыть `HumorQuiz.sln` и нажать F5.
- Командная строка:
  ```
  dotnet run --project HumorQuiz
  ```

## Структура

| Файл | Назначение |
|------|------------|
| `Program.cs` | Точка входа |
| `StartForm.cs` | Стартовое окно и переходы между окнами |
| `QuestionForm.cs` | Окно с вопросом и проверкой ответа |
| `ResultForm.cs` | Окно итогов |
| `Question.cs` | Модель вопроса |
| `QuestionBank.cs` | Все 15 вопросов — здесь легко добавить или изменить свои |
| `QuizSession.cs` | Состояние игры (текущий вопрос, ошибки) |
